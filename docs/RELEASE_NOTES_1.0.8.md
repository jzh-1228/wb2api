# wb2api 1.0.8

> 历史版本公告。项目名称已统一，旧下载链接已移除，安装包旧前缀以 `***` 隐去；内容保留当时的更新与验证记录，不代表本轮重新验证。

## 更新内容

- **改善 Android 后台连续对话和 Agent 长任务的稳定性。** 修复本地探活响应较慢时误重启仍存活的服务、切断正在进行的回答的问题；返回工作台时也保留已有连接。优化 API 线程优先级，继续使用前台服务与 CPU 保活。
- **修正网络故障与账号状态的判断。** 网络传输错误不再人为冷却或降权整个账号；模型供应商临时不可用不会累计整账号熔断。尚未收到响应头时，部分连接故障可在共享重试预算内尝试一次新连接恢复；已经输出的回答不会自动重放。
- **用量日志支持完整排障。** 调用诊断入口移到用量日志，增加成功/错误数量、结果筛选、可点击详情和脱敏诊断导出。分别展示网关处理结果、真实上游 HTTP、业务 code、msg 与响应原文，以及本地网络异常和失败阶段。没有收到上游响应时明确说明；未记录账号的请求不再显示成虚构的“账号 #0”。服务端、Windows 和 Android 均采集新请求的诊断。
- **新增 Android 运行状态诊断。** 可查看网络状态、后台限制、省电和休眠状态、CPU 保活及本地事件循环停顿采样，帮助区分本地调度问题与上游错误。诊断不保存请求正文或凭据；较长错误原文会脱敏并标明截断。
- **失效账号可原位重新登录。** 支持上传或粘贴最新凭据，也支持手机号验证码重新登录；核验原账号身份后保留账号 ID、排序、Key 绑定和历史记录。重新登录不会清除真实模型日限。
- **新建 API Key 默认不限额。** 不填额度即无限制；显式填写数字才按限额执行，填写 0 表示零额度。Key 额度耗尽时返回 HTTP 402 和 `key_quota_exceeded`，明确提示当前 Key 额度已用完。已有 Key 的限额保持不变。
- **改善启动体验。** 更新启动页面，Android 初始化文案居中，首次进入工作台增加短暂淡入淡出。启动超时或失败时可在服务尚未就绪的页面查看、复制或导出启动诊断，并重试，无需删除账号数据。Windows App 继续免登录自动进入本地工作台。

## 验证结果

- 线上已部署并重启至 1.0.8，管理接口、日志统计/筛选/导出及诊断持久化检查通过；Chat、Responses、Messages 的流式和非流式六种调用均正常完成。
- 服务器隔离环境 87 项回归、本地补充 53 项回归通过；双端运行环境启动检查和 Android lint 通过。
- 正式签名 APK 在 Android 模拟器完成三次冷启动；DeepSeek V4.1 Flash 与零倍率 hunyuan-chat 的 48 次前后台连续对话全部成功，另有 12 次协议调用及取消后的下一轮请求通过，结束时无残留活动请求。测试数据已清理。
- 此前通过实际 Operit AI 界面完成的 Agent 长任务共 60 次模型请求无网关错误。用户在 vivo X300 Pro / Android 17 真机后台复测反馈，稳定性明显改善。
- 打包后的 EXE 在独立空数据目录中自动进入工作台；双端版本、包内修复代码、SHA256 与 Android 原签名均已核验。

短连接测速通过不能代表长任务或后台运行一定正常；本次已针对确认的误重启机制修复，并补充连续调用验证。旧日志未保存的上游详情无法追溯，新请求会保存诊断。

## 安装与升级

- Android：下载 `***-1.0.8-android-arm64.apk`，直接覆盖安装，保留账号和配置。后台使用时请允许前台服务通知，并按手机系统设置允许后台运行。
- Windows：关闭旧版后运行 `***-1.0.8-windows-x64.exe`。
- 无需卸载或清除应用数据。两个安装包均提供 `.sha256` 校验文件。
