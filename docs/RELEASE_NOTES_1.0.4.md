# wb2api 1.0.4 更新公告

> 历史版本公告。项目名称已统一，旧下载链接已移除，安装包旧前缀以 `***` 隐去；内容保留当时的更新与验证记录，不代表本轮重新验证。

本次更新新增每日权益检查领取和 DeepSeek 补偿一键领取，优化账号池批量刷新、执行进度和重复点击保护。

## 更新内容

- 修复 Android 启动时批量领取接口的 Pydantic 1 列表约束兼容错误；构建新增独立依赖环境下的服务启动与参数校验检查，Windows 和 Android 均在打包前验证。
- 新增 **DeepSeek 模型服务异常额外补偿 500 积分**领取入口。在“账号池 → 管理操作 → 额度与批量管理”点击一键领取，确认后为全部启用账号执行，无需勾选账号。**请于 2026 年 10 月 22 日 23:59:59（北京时间）前领取**，资格及到账结果以官方为准。
- 新增“**每日检查并领取权益**”定时任务，默认每天检查一次，根据官方返回的活动金额、截止时间和领取状态自动领取。移除 DeepSeek 专属自动设置菜单，保留本次补偿的手动入口；旧自动任务升级时迁移，保留原启停状态。本次活动结束后，每日权益任务继续检查该官方接口后续提供的活动。
- 优化领取可靠性：按账号和活动记录领取结果，超时后先核对官方状态，避免立即重复提交；账号忙碌或受保护时顺延处理。领取成功后自动刷新余额与积分到期快照，刷新失败不会重复领取已到账权益。
- 修复账号池“**刷新全部**”由浏览器逐账号发请求的问题，改为一次 POST 提交后台批量任务，并显示成功、失败和跳过数量。
- 统一补偿领取、全部刷新、成长任务、猫猫旅行等批量操作的准备状态、加载提示、按钮禁用和重复点击保护。同类型任务执行中再次提交会复用当前任务。
- 完善批量任务进度：显示当前处理账号与执行进度，完成后弹窗汇总结果；补偿领取额外显示本次获得的总积分。关闭进度弹窗后任务继续运行，可通过“执行中 · 查看进度”重新查看。

## 下载与升级

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `***-1.0.4-windows-x64.exe` |
| Android ARM64（Android 7.0 及以上） | `***-1.0.4-android-arm64.apk` |

Windows 使用新版 EXE；安卓使用同签名 APK 覆盖安装，保留账号和配置。两个安装包均附带 `.sha256` 校验文件。

服务端更新源码及依赖后重启服务，旧权益任务自动迁移。可在“定时任务”中查看每日权益检查的启停状态与执行结果。

## 说明

- 每日权益检查支持已接入官方接口返回的后续活动；通过其他接口发放的新福利需要另行接入。
- 已领取、未开放、已截止或不符合资格的活动不会重复发起领取。
- 批量任务处理的账号较多时需要一定时间，请通过进度弹窗查看结果。
