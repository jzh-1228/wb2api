# wb2api 1.0.2 更新公告

> 历史版本公告。项目名称已统一，旧下载链接已移除，安装包旧前缀以 `***` 隐去；内容保留当时的更新与验证记录，不代表本轮重新验证。

本次更新重点加固 2api 反代的账号池调度、模型权限与冷却监测。

## 更新内容

- 后台保活、余额与模型信息刷新统一节流，优先使用空闲账号；遇到账号冷却、在途占用或出口保护时跳过或顺延，减少与正常对话争用账号。
- 尊重上游明确返回的重置时间和 Retry-After，避免本地退避上限提前结束冷却；区分账号级保护与账号下的模型限制。
- 模型健康页面增加近 15 分钟的风控观测、出口保护与后台跳过统计。数据来自实际调用记录，不额外发起模型探测。
- 修复 Anthropic 模型映射将被移出分组或禁用的具体模型静默转为 auto 的问题，以及模型全部禁用时错误放行的问题。
- 优化“模型额度与冷却”弹窗：限制明细前置，不可用及受限模型优先展示，便于排查。
- `/v1/models` 每次获取时从官方上游刷新倍率与繁忙程度，展示名称包含倍率和繁忙状态；上游状态缺失或查询失败时显示“未知”。**模型 ID 保持官方原值，调用方式不变。** 部分客户端只显示 ID，不会展示扩展名称。

## 下载与升级

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `***-1.0.2-windows-x64.exe` |
| Android ARM64（Android 7.0 及以上） | `***-1.0.2-android-arm64.apk` |

Windows 使用新版 EXE；安卓使用同签名 APK 覆盖安装，可保留账号和配置。两个安装包均提供对应的 `.sha256` 校验文件。

## 使用说明

- 分组权限作用于绑定该分组的 API Key；未绑定分组的 Key 按全局模型配置调用。
- 冷却截止表示可再次尝试的时刻，不保证上游已经恢复；页面会区分上游明确重置时间与本地退避依据。
