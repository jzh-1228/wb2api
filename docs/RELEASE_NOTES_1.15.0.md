# wb2api 1.15.0

本版改进共享 Key 的容量调度，增加 AI 生图和邀请绑定，并修复 DSH 项目规则在脱敏时丢失的问题。

## DSH 与项目规则

- 自动识别 `system-reminder` 中 `Instructions from: …/AGENTS.md:` 的项目规则，单独提取并转发，无需每次手动粘贴。
- 项目规则不参与可选文本脱敏、运行时摘要或 Responses 历史截断；支持多份规则、Windows 路径和图片消息。
- 对已确认会导致 `11128` 的固定身份句、PR 模板短语保留必要的兼容归一，避免 system 消息内的规则再次触发拦截。业务指令保留，来源标题中的本地路径省略。
- Chat、Responses、Messages 均已覆盖，原有模型映射与思考档位配置保持不变。

## 并发与客户端兼容

- 共享容量按 Key 公平轮转，选号与并发占位合并处理，账号释放后唤醒等待请求。
- 增加吞吐优先选号策略，优先使用并发占用比例较低的可用账号，兼顾会话粘性和积分到期；可在策略设置中选择。
- 改进 CC 客户端自适应思考参数兼容，保留用户明确指定的思考意图。
- 合并请求时长、注册请求准入和日志统计缓存方面的稳定性改进。

## AI 生图

- 支持文生图 `/v1/images/generations` 与图生图 `/v1/images/edits`，包括 `hunyuan-image-alpha`。
- 按上游返回的实际积分记录生图用量，图片模型不再按免费文本模型展示或计费。
- 模型列表增加 IMAGE / TEXT 类型标签，便于区分调用用途。

## 账号与设置

- 网页与 Windows 设置页支持填写官方邀请链接或邀请码，新注册会话使用保存的邀请配置。
- 账号先校验并入库，再尝试绑定邀请；邀请失败会显示状态，不影响已录入账号使用。
- 调整设置页对齐、控件间距和移动端布局。
- 余额初始化遇到鉴权失败时给出明确状态，避免将非 JSON 的 401 响应误报为 JSON 解析异常。国际版凭证访问国内接口时提示区域不兼容。

## 验证与升级

- 修正后完成 20 组实际上游规则测试及 12 组公网协议测试，覆盖 system/user 规则和三个协议的流式、非流式请求；测试规则均生效，未出现 `11128`。
- Windows EXE 已完成独立空数据目录下的原生窗口、自动登录与版本角标冒烟测试。
- Android APK 已通过固定依赖启动检查、lint、包内代码与版本校验，签名与上一正式版一致；本次未连接安卓设备，未执行安装和前后台连续对话测试。
- 已使用 1.14.0 新仓库更新源的客户端可检查更新；也可下载对应平台包手动升级。升级保留已有账号、Key 和配置。

附件包含 Windows x64 EXE、Android arm64 APK，以及各自的 SHA256 校验文件。
