# wb2api 1.16.0

本版增加账号池的权威健康检查，修复登录态误判，并移除已结束的 DeepSeek 限时补偿功能。

## 账号池健康检查

- 账号池每个账号支持单独健康检查，批量菜单支持“一键健康检查”。
- 每个账号依次验证积分、模型目录和一次最小真实上游对话；三项都通过才显示为健康。
- 检查失败只记录诊断结果，不会因为一次接口异常自动禁用账号。
- 成功检查可以恢复由登录态失效自动停用的账号，手动停用账号不会被自动恢复。
- 页面展示每一阶段的状态、耗时、余额、模型数量、实际探测模型和错误原因；真实对话检查可能消耗少量上游积分。

## 登录态与上游兼容

- 修正上游认证异常的可信判断，模型接口的单独 401 不再被当作账号退出登录。
- 去除客户端未发送的额外上游请求头，减少因请求形态差异造成的误报。
- 保留真实上游错误和请求日志，便于区分账号失效、模型限额和网关自身异常。

## DeepSeek 补偿功能

- DeepSeek 限时补偿活动已结束，移除补偿按钮、接口、定时任务和相关前端代码。
- 旧补偿接口现在返回 404，升级时会清理遗留的补偿模块和调度记录。

## 更新与验证

- 线上服务已部署并重启，版本接口显示 1.16.0，升级等待队列回落为 0。
- 公网 Chat Completions、Responses、Messages 三种协议的流式与非流式请求共 12 组全部通过，测试 Key 已清理。
- Windows EXE 已在独立空数据目录完成原生窗口、自动登录和版本角标冒烟测试。
- Android APK 已通过固定依赖启动检查、lint、包内源码/版本/签名校验；未连接 Android 真机，未执行安装和前后台连续对话测试。

附件包含 Windows x64 EXE、Android arm64 APK，以及各自的 SHA256 校验文件。
