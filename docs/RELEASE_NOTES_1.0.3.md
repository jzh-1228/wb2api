# wb2api 1.0.3 更新公告

> 历史版本公告。项目名称已统一，旧下载链接已移除，安装包旧前缀以 `***` 隐去；内容保留当时的更新与验证记录，不代表本轮重新验证。

本次更新优化登录、局域网接入、客户端稳定性和管理界面，并更新账号凭证导出格式。

## 更新内容

- 手机号登录与 `/join` 新增中国香港 `+852`、中国澳门 `+853`，优化区号下拉和号码校验；保留待验证手机号及倒计时，登录弹窗只能通过关闭按钮关闭，增加短信发送防重复与出口限流。
- Windows EXE 和 Android APK 自动进入本地工作台，修复本地授权失效后的 401 中断；默认支持局域网访问，API Keys 页面可选择并复制检测到的局域网 IP 地址。
- 启动时检查更新并展示公告，支持“稍后再说”和“暂不更新此版本”，可通过更新入口再次查看和下载。
- 优化安卓后台服务及通知、电池优化和后台授权状态检查，便于保持后台运行。
- 新导入账号、定时任务及奖励领取后自动刷新余额与积分到期快照。
- 优化 Anthropic thinking / effort 参数兼容及可恢复的上游错误处理，减少对话中断。
- 修复模型配置批量操作；“显示倍率”“显示繁忙程度”控制 `/v1/models` 返回的模型名称，模型 ID 保持不变。新增实际请求检测，展示首字延迟、响应耗时、抖动及健康状态。
- 新增浅色/深色主题切换，统一各页面表格、输入框、下拉框边框和滚动条配色；改善手机模型表格布局，用量日志改用可搜索的模型与 Key 下拉。
- Tooltip 支持移入、滚动、选中和复制内容，API 接入示例同步适配主题。
- 账号默认导出官方新版加密 `.info` 格式，批量导出加密 `.jsonl`，保留“系统明文备份”选项。加密导出需要可用的官方客户端密钥配置。
- 整理 README，截图和模块说明前置，协议说明移至 `docs/`；补充 Linux Docker 部署，默认只启动 admin 容器，可选启用 converter。

## 下载与升级

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `***-1.0.3-windows-x64.exe` |
| Android ARM64（Android 7.0 及以上） | `***-1.0.3-android-arm64.apk` |

Windows 使用新版 EXE；安卓使用同签名 APK 覆盖安装，保留账号和配置。两个安装包均附带 `.sha256` 校验文件。

## 注意事项

- 模型检测会发送实际短请求并消耗少量额度，检测结果代表当次账号和网络状况。
- 向未配置解密密钥的安卓端迁移账号时，请在电脑端选择“系统明文备份”，或在手机直接登录。明文备份包含账号凭证，请妥善保管。
- 安卓后台运行仍受系统和厂商省电策略影响，请允许通知和后台运行，并按需取消电池优化。
