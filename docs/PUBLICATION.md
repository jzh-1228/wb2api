# wb2api 文档公开与迁移约定

公开文档统一使用 `wb2api`，上游客户端称为 `wb`。必要的旧名称、安装包前缀和私有路径以 `***` 隐去；占位符不能用于实际配置。

系统名称、界面、发行包前缀和项目目录统一为 wb2api，公开说明与客户端接入示例同步整理。上游实际域名、协议字段、环境变量名、Android 标识、数据库路径和功能代码继续保留，避免破坏运行兼容性。Android 应用标识、签名和已有运行数据目录保持升级兼容。

`docs/` 仅公开本文件和以数字版本号命名的 `RELEASE_NOTES_X.Y.Z.md`。协议研究、逆向分析、取证记录、抓包、历史排障、内部评审和工作草稿均保存到仓库外，不得加入公开文档例外规则。

旧截图已移到仓库外；公开说明暂不展示，后续使用经过核验的新截图。

迁移使用整理后的源码快照，纳入当前未提交的产品源码修改；不复制旧 `.git`、内部资料、凭据、本地部署脚本、数据库、签名、构建产物或缓存。仅新增忽略规则无法清除已经跟踪的资料，旧 Git 历史也不得直接推送至新仓库。

版本以 `desktop/version.json` 为准，正式源码和更新源为 [xiaofan6ya/wb2api](https://github.com/xiaofan6ya/wb2api)。本次迁移从干净源码建立全新 Git 历史。旧版需要手动安装 1.14.0，此后从新仓库检查更新。

项目和第三方依赖的许可证、作者署名继续保留。历史公告只调整公开称呼与旧链接，不追溯改写当时的测试结论。
