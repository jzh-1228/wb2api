# wb2api 1.11.0

> 历史版本公告。项目名称已统一，旧下载链接已移除，安装包旧前缀以 `***` 隐去；内容保留当时的更新与验证记录，不代表本轮重新验证。

本次更新优化 Windows 客户端与 Android App 的顶部布局、版本入口和启动更新提示，修复 DSH 已知身份句触发的 11128，并改进定时任务配置。

## 更新内容

- **客户端与 App 顶部区域优化**。Windows 使用自定义窗口按钮，支持顶部拖动和边缘缩放；Android 由原生布局统一处理状态栏、刘海、导航栏和键盘安全区，滚动正文时不再露到系统状态栏后面，并同步系统栏的明暗主题。
- **版本入口位置优化**。Windows 宽屏下保留左下角版本入口；App 与窄屏界面将版本按钮放在左侧折叠菜单的 API URL 下方，取消遮挡正文的悬浮按钮。
- **双端启动检测更新并询问用户**。发现新版本时显示“立即更新 / 暂不更新”；暂不更新后继续使用当前版本，下次启动仍可提示。Windows 仅启动到托盘时也会检查更新；确认后下载、校验并重启安装，退出时一并关闭托盘宿主，避免更新程序等待旧进程。Android 确认后打开最新版 APK 下载，安装仍由系统确认。
- **修复国内上游已知的 11128 触发场景**。对 system/developer 中已知不兼容的智能体身份声明做通用句式归一，不绑定 DSH 品牌，保留智能体名称和后续任务指令；关闭脱敏时也会执行。Chat、Responses、Messages 三协议及独立转换网关均覆盖，用户正文、工具参数和工具结果不在此项归一的改写范围内。已复现原始 DSH 身份句返回 400/11128，修复后同一句原始输入在三协议流式/非流式均正常完成。仍收到结构化 11128 时，不再触发无意义的换号重放或账号冷却，并保留上游原始错误。
- **定时任务支持日历周期**。除系统预设和间隔执行外，支持每天、每周多日、每月指定日期，按北京时间计算下次执行时间；任务列表与成长计划显示实际周期。兼容旧任务配置，并处理旧版 MySQL 不接受 TEXT 默认值的迁移问题。

## 下载与升级

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `***-1.11.0-windows-x64.exe` |
| Android ARM64（Android 7.0 及以上） | `***-1.11.0-android-arm64.apk` |

Windows 可使用新版 EXE 替换旧版；Android 使用同签名 APK 覆盖安装，保留原账号和配置。两个安装包均提供 `.sha256` 校验文件。

本次已重新打包替换 1.11.0 附件。若已下载本版早期安装包，请重新下载并覆盖安装。

## 验证范围

- 线上部署并重启，核对版本、数据库迁移、管理接口和鉴权；Chat、Responses、Messages 三种协议的流式与非流式真实请求均通过，临时测试 Key 已清理。
- 本次修复涉及的兼容、协议、流式、账号策略与启动更新等回归共 207 项通过；包含两套网关、三协议、流式/非流式及脱敏开关的 24 种身份句请求组合。
- 打包后的 Windows EXE 在独立空数据目录通过原生窗口冒烟；检查 4 种窗口尺寸下的版本入口、折叠菜单，以及使用受控新版本数据的启动提示、暂不更新和确认更新流程。
- 重新打包的正式签名 APK 在 Android 9 模拟器完成 3 次冷启动；携带原始 DSH 身份句进行两种模型的前后台、恢复及 48 轮连续真实对话，三协议共 12 项流式/非流式请求与取消后恢复检查均通过，测试后无活动请求，原模拟器数据已恢复。顶部安全区、菜单内版本按钮和更新弹窗已在本版布局验证中检查。未进行安卓真机验证。
- 双端包内代码与资源、版本及 SHA256 核对通过；Android 签名与上一正式版本一致，固定依赖启动检查和 lint 通过。
