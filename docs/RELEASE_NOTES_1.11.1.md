# wb2api 1.11.1

> 历史版本公告。项目名称已统一，旧下载链接已移除，安装包旧前缀以 `***` 隐去；内容保留当时的更新与验证记录，不代表本轮重新验证。

本次补丁修复 Mac 端 Zcode 的已知提示词 11128 触发场景，并优化定时任务配置界面。

## 更新内容

- **修复 Mac 端 Zcode 提示词触发 11128**。会话工作目录包含 Git 仓库时，gitStatus 中的主分支说明可能触发上游渠道校验。现在全局移除 `Main branch` 后已确认不兼容的固定括号注释，保留实际分支名和其余 Git 状态，例如输出为 `Main branch: main` 或 `Main branch: master`。覆盖后续上下文中的重复内容，关闭脱敏时也生效；相同模板的其它智能体共用此项兼容处理，已有 DSH 修复继续保留。
- **优化定时任务配置 UI**。任务类型、执行周期和间隔单位改用统一样式的下拉菜单；执行日改为多选按钮，启用状态改为开关；执行时间和停止时间使用统一的时间、日期选择面板。适配桌面、手机及浅色、深色主题，并完善键盘操作、时间校验和重复打开弹窗的行为。

## 下载与升级

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | `***-1.11.1-windows-x64.exe` |
| Android ARM64（Android 7.0 及以上） | `***-1.11.1-android-arm64.apk` |

Windows 使用新版 EXE 更新；Android 使用同签名 APK 覆盖安装，保留账号与配置。两个安装包均提供 `.sha256` 校验文件，1.11.0 客户端可通过更新检查发现本版。

## 验证范围

- 已部署线上并重启，核对 1.11.1 版本、管理接口、页面资源和鉴权。原始 Mac 日志请求由 400/11128 修复为 200 并收到响应内容；携带 Zcode 主分支模板与 DSH 身份句的三协议流式、非流式六项真实请求通过，临时测试 Key 已清理。
- 149 项相关回归测试通过，覆盖两套网关、协议转换、脱敏开关、重复模板、分支名保留、请求长度和定时任务周期；桌面、手机浅色与深色四种配置界面验证通过，APK 内提取的界面资源也通过相同检查。
- 打包后的 Windows EXE 在独立空数据目录通过原生窗口启动和版本显示检查。APK 固定依赖启动检查、lint、包内代码、版本及 SHA256 核验通过，Android 签名与 1.11.0 一致。
