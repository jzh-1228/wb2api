# wb2api 1.0.7

> 历史版本公告。项目名称已统一，旧下载链接已移除，安装包旧前缀以 `***` 隐去；内容保留当时的更新与验证记录，不代表本轮重新验证。

## 更新内容

- 修复请求内容或参数类 400 错误累积后，将健康账号误降权的问题，减少小账号池出现本地误判“没有可用账号”的情况。
- 修复部分模型不可用错误未继续尝试备用账号的问题。同一模型优先尝试其它符合条件的账号，保留真实模型限额、账号归属、并发限制及重试预算。
- 修复刷新后的登录凭据在对话失败时未及时保存，以及并发请求重复刷新、旧请求结算覆盖新凭据的问题，降低由本地令牌处理引发的登录失效风险。
- 修复 Chat 流式接口将上游 400 包装为 HTTP 200、却没有有效回答的问题。错误状态和错误事件现在能被客户端明确识别。
- 改进 Android“调用诊断”详情：分别展示网关返回 HTTP、实际收到的上游 HTTP、上游业务 code、原始 msg 和网关处理分类；换号前的失败信息也会保留，避免把网关最终 503 当成上游真实状态。
- 诊断消息保留原文并进行安全转义；超过展示长度会明确提示截断，没有收到上游 HTTP 响应时也会明确说明。
- Windows 和 Android App 继续自动进入本地工作台，无需输入后台账号密码。

## 验证结果

- 86 项本地回归通过；服务器隔离回归和启动检查通过。线上部署重启后，六种协议模式及相关接口共 15 项检查通过。
- 实际安装正式签名 APK，在 Android 模拟器中使用两个账号，以约每 3 秒一次的频率测试 DeepSeek V4.1 Flash 和零倍率 hunyuan-chat，48 次前后台连续对话全部成功。
- 正式 APK 的两模型、三种协议、流式与非流式共 12 次调用全部成功，取消回答后的下一次请求也正常完成，测试结束时活动请求为空。
- 此前的隔离模型冷却测试中，两个模型分别冷却一个账号后，8 次请求均由另一个正常账号实际回答。
- 正式 APK 三次冷启动通过；打包后的 EXE 在独立空数据目录中自动进入工作台，版本显示为 v1.0.7。双端包内版本、修复代码、SHA256 和 Android 原签名均已核验。
- Android 验证使用模拟器，尚未在用户反馈问题的真机网络环境复测。本次修复针对已确认的本地错误机制，不代表已复现或排除所有手机网络、省电及后台限制问题。

## 安装与升级

- Android：下载 `***-1.0.7-android-arm64.apk`，直接覆盖升级。
- Windows：关闭旧版后运行 `***-1.0.7-windows-x64.exe`。
- 保留原有账号与配置，无需卸载或清除应用数据。两个安装包均附带 `.sha256` 校验文件。
