# wb2api 1.0.9

> 历史版本公告。项目名称已统一，旧下载链接已移除，安装包旧前缀以 `***` 隐去；内容保留当时的更新与验证记录，不代表本轮重新验证。

本次更新完善积分流水、使用记录和更新备份页面，并发布此前针对 Issues #27、#28 与 PR #26、#29 完成的功能和兼容性改进。

## 更新内容

- **积分流水**：独立展示奖励记录与余额变化，支持账号、来源、类型、时间筛选和分页；下拉框支持搜索，日期选择器适配浅色、深色主题。积分增加显示绿色 `+`，减少显示红色 `-`。
- **历史数据说明**：分批导入已有成长奖励记录；确认奖励与余额观察分别记录，不能相加统计。历史没有保存的来源或余额显示为未记录。
- **使用记录**：新增开始、结束日期查询，按本地日期包含结束当天；统计卡片、图表和模型筛选选项使用相同时间范围。用量日志也使用统一样式的日期选择器。
- **页面整理**：仅账号池、积分到期页面保留顶部总览卡片；调整暗色主题的蓝紫标签、头像、按钮边框和禁用状态，改善手机布局。
- **更新与备份**：分开展示版本、数据备份与升级步骤，支持 Docker Compose / Linux 命令切换、命令高亮和一键复制。SQLite 支持管理员在线备份下载；MySQL 提供备份命令指引。
- **账号并发配置**：每个账号可单独设置并发上限：留空跟随全局，`0` 不限，正整数指定上限；维护任务互斥保护继续生效。
- **协议兼容**：修正静态资源 MIME，保留工具及参数说明，以及混合运行时提示中的真实用户文字与图片，改善智能体对接兼容性。
- **旧版凭证导入**：导入和重新登录入口支持选择 `.info.bak-时间戳` 等备份文件，按内容校验并验证上游有效性。Android 导入新版 Windows 加密凭证前，请先在电脑导出“系统明文备份”，或使用手机号授权登录。

## 安装与升级

- Windows 下载 `***-1.0.9-windows-x64.exe`，关闭旧程序后运行新版；沿用原数据目录可保留账号与配置。
- Android 下载 `***-1.0.9-android-arm64.apk` 覆盖安装，签名与上一正式版一致；保留应用数据，无需卸载旧版。
- 服务器升级前先备份数据库和部署配置。管理台提供升级指引，实际更新与重启由管理员执行。
- 两个平台均附带 `.sha256` 校验文件，旧版客户端可通过检查更新获取对应平台安装包及公告。
