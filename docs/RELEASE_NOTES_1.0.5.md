# wb2api 1.0.5

> 历史版本公告。项目名称已统一，旧下载链接已移除，安装包旧前缀以 `***` 隐去；内容保留当时的更新与验证记录，不代表本轮重新验证。

## 更新内容

- 修复账号更新凭据后仍被标记为“登录态失效”的问题，覆盖单条导入和批量导入；手动停用的账号保持停用。
- 错误提示对照 wb 客户端及 CLI 重新校正，分别展示本网关判断、客户端解释和上游原始 HTTP 状态、业务 code、message 与响应原文，便于排查实际原因。
- Windows 和 Android 本地 App 继续免填后台账号密码，优化自动会话准备与刷新，避免将上游账号凭据失效误认为 App 需要登录。
- 账号到期排行支持上移、下移及恢复自动排序。调整前会明确确认，保存后直接改变真实账号的使用优先级；账号健康、模型冷却和并发限制继续生效。
- 修复“模型额度与冷却”统计遗漏，区分官方额度与本网关用量；上游未提供的额度显示“未知”，缺少 Token 记录时显示“未记录”。
- 区分每日 Token 上限（6004）、每日请求上限（6008）、短时限流及模型排队。6008 按客户端说明在次日零点重置；优先采用上游返回的恢复时间，本地估计会单独标明。
- 修复 Responses 非流式请求在账号轮转失败后丢失最后一次上游错误的问题，完善 Chat、Responses、Messages 的流式与非流式错误返回。

## 安装与升级

- Windows：下载 `***-1.0.5-windows-x64.exe`，关闭旧版后运行新版。
- Android：下载 `***-1.0.5-android-arm64.apk`，使用同签名安装包覆盖升级。
- 覆盖升级保留原有账号和配置，无需卸载旧版。两个安装包均附带 `.sha256` 校验文件。

## 说明

- 模型每日限制按账号和模型分别记录，免费模型也可能触发日限。
- 冷却截止仅表示可以再次尝试，不保证届时上游一定恢复。6004 未给出恢复时间时，默认采用本地保守等待 24 小时，并明确显示时间依据。
- 本网关记录的用量不包含其他客户端消耗，不能据此推算官方剩余额度。历史已经截断的上游原文无法补回，新错误将保留完整收到的诊断信息。
