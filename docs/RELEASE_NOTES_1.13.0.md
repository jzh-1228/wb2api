# wb2api 1.13.0

> 历史版本公告。项目名称已统一，旧下载链接已移除，安装包旧前缀以 `***` 隐去；内容保留当时的更新与验证记录，不代表本轮重新验证。

本次正式版修复定时任务中的专家体验任务与账号保活，完善请求状态、账号用量统计，以及 Windows / Android 客户端的参数同步和文件导出。

## 更新内容

- **专家体验任务自动识别**。从官方任务描述中提取需要召唤的专家名称，精确搜索专家并完成对话，再刷新进度、领取奖励。同类新增专家任务无需逐个追加任务代码；已实测「无畏契约拼豆专家」进度从 0/1 变为 1/1 并领取奖励。
- **保活覆盖受保护账号**。保护、冷却和风控状态不再成为跳过 token 刷新的理由，刷新时保留原有保护状态；先保存轮换后的凭据，再执行可选业务探测。账号存在在途请求时先等待排空，仍忙碌的账号加入待重试集合，一分钟后继续，避免长期遗漏。
- **请求状态更准确**。完成响应的 HTTP 200 不再误标成客户端断开；提前断开的请求以橙色显示「客户端提前结束」，上游失败继续显示错误状态。结合流式终止事件判断完成，保留诊断信息。
- **使用记录支持按账号查看**。新增账号筛选、各模型的请求量、成功用量、积分和已观测到的限制及重置时间。底部补充账号分布、请求结果分布，共六项图表；免费模型仍参与统计，无积分消耗时按成功请求数展示分布。统计仅包含经过本网关的用量，不推算上游未公开的总配额或剩余额度。
- **客户端参数支持导入导出**。可导出统一 JSON 参数文件，Windows、浏览器和 Android 共用格式；Android 设置页新增导入、导出入口。导入前校验文件，导入成功后自动启用保存的参数，新请求立即生效。
- **修复客户端账号导出**。Windows 调用原生文件保存窗口，Android 调用系统文档保存器，补齐 JSONL 等文件类型和失败、取消提示。Android 默认导出可跨端导入的账号备份，避免依赖 Windows 专有凭据加密；账号备份含登录凭据，请自行妥善保存。

## 下载与升级

| 平台 | 安装包 |
| --- | --- |
| Windows x64 | ***-1.13.0-windows-x64.exe（原链接已移除） |
| Android ARM64（Android 7.0 及以上） | ***-1.13.0-android-arm64.apk（原链接已移除） |

Windows 使用新版 EXE 更新；Android 使用同签名 APK 覆盖安装，保留账号与配置。两个安装包均附带 `.sha256` 校验文件。

同步客户端参数时，在已有正确参数的客户端导出 JSON，再到另一客户端的参数页或 Android「设置 → 客户端参数」导入，成功后即启用。
