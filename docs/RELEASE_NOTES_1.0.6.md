# wb2api 1.0.6

> 历史版本公告。项目名称已统一，旧下载链接已移除，安装包旧前缀以 `***` 隐去；内容保留当时的更新与验证记录，不代表本轮重新验证。

## 更新内容

- 修复 Android 流式请求等待上游首段内容时没有心跳的问题。现在从等待阶段起每 5 秒发送保活心跳，降低慢首包触发聊天客户端读取超时的概率，覆盖 Chat、Responses 和 Messages 三种接口。
- 修复客户端在首包前取消请求后，上游请求仍继续运行的问题。断开监听提前启动，取消时清理流、连接和账号占用，避免影响下一轮对话。
- 保留心跳发出前的 HTTP 错误状态及重试提示；流已开始后的错误继续通过对应协议明确返回，不把失败伪装成正常结束。
- 修复 Android 增量构建的源码准备顺序，避免安装包版本号已更新、后端仍打入上次源码的问题，并补充包内修复代码核验。
- Windows 和 Android App 继续自动进入本地工作台，无需填写后台账号密码。

## 验证结果

- 86 项本地回归通过；线上重启后六种协议模式及相关接口共 15 项检查通过。
- Android 模拟器完成前后台连续对话、三协议流式与非流式请求、取消后重试，共 21 次实际上游调用全部成功，测试结束后活动请求和账号占用均为 0。
- 在 Android 内嵌服务注入 8 秒首包等待、客户端读取超时设为 6 秒：旧逻辑超时，新逻辑约 5 秒发送心跳、8 秒后正常完成。首包前取消后已验证资源释放。
- 正式 APK 安装及 3 次冷启动通过；打包后的 EXE 自动进入工作台冒烟通过。双端包内版本、修复代码、SHA256 及 Android 原签名均已核验。
- 本次 Android 设备验证使用模拟器，尚未在用户反馈问题的真机网络环境复测。

## 安装与升级

- Android：下载 `***-1.0.6-android-arm64.apk`，直接覆盖升级。
- Windows：关闭旧版后运行 `***-1.0.6-windows-x64.exe`。
- 保留原有账号与配置，无需卸载或清除应用数据。两个安装包均附带 `.sha256` 校验文件。
